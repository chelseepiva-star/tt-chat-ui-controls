# 聊天显示控制 v1.2（SillyTavern / TauriTavern 前端扩展）

用于把三个视觉层真正拆开：

1. **最底层背景图片**：新增“背景图片模糊强度”，只作用于 `#bg1`。
2. **聊天正文卡片 + 文字**：保持清晰，不再用全局 UI 模糊去糊背景；聊天正文颜色可独立设置。
3. **设置窗口 / 弹窗 / 顶部栏 / 输入区等 UI**：继续由原生“模糊强度”控制，扩展只把标签改成“UI 模糊强度”。

## 新增设置

用户设置 → UI 主题：

- 主题颜色 → **聊天正文颜色**
- 原生 **模糊强度** → 显示为 **UI 模糊强度**
- 新增 **背景图片模糊强度**（0 最清晰，30 最模糊）

## 安装

推荐：在 TauriTavern 内使用 **扩展 → 安装扩展**，粘贴承载本目录的 Git 仓库 URL。

手动目录（有文件系统访问能力时）：

`data/default-user/extensions/chat-text-color-extension/`

目录内直接放：`manifest.json`、`index.js`、`style.css`、`README.md`。
